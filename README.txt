PolitElections для Paper 1.21.11 + Towny

КОМАНДЫ
/election start   - начать выборы (админ)
/election end     - закончить выборы и назначить председателя (админ)
/election run     - мэр выдвигает себя
/election vote <ник> - мэр отдаёт голос своего города (вес = число жителей)
/election status  - кандидаты и голоса
/chairman         - меню председателя

КАК СОБРАТЬ ПЛАГИН (без установки программ)
1. Создай аккаунт на github.com и новый репозиторий.
2. Загрузи в него ВСЕ файлы из этой папки (включая скрытую папку .github).
3. Открой вкладку Actions, дождись зелёной галочки у запуска Build.
4. Открой запуск, внизу в Artifacts скачай PolitElections.
5. Внутри архива будет PolitElections.jar. Положи его в plugins сервера.

Если сборка красная, скопируй текст ошибки и пришли его Клоду.
